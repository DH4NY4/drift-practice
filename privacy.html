Privacy policy

Last updated: September 20, 2026

The short version: this site doesn't have accounts, doesn't ask you for any personal information, and doesn't run its own server — so there's essentially nothing here to collect it with. The longer version below explains exactly what does and doesn't happen when you use it.

No accounts, no sign-up

There's no login, no registration, and no way to identify you as a returning visitor. You can use every game on this site without providing a name, email address, or any other personal detail.

What happens to your game data

Scores, streaks, and progress within a game exist only in your browser's memory for as long as the page stays open. Nothing is sent to a server, because this site doesn't have one — it's a static set of files that runs entirely in your browser. Close or reload the page and that session's progress is gone; it was never stored anywhere to begin with.

Cookies set by this site

This site itself does not set any cookies and does not use browser storage (such as localStorage) to remember anything about you between visits.

If advertising is enabled

This site may display ads served by a third-party advertising network (such as Google AdSense). If and when that's active, the ad network itself — not this site — may use cookies or similar technology to serve ads and measure performance, and some networks use that data to personalise which ads you see. That's governed by the advertising network's own privacy policy, not this one, since this site never receives or stores that data itself. If you'd prefer not to see personalised ads, most ad networks provide an opt-out through their own settings pages, and browser extensions that block third-party tracking will also work here without breaking any of the games.

Analytics

This site does not currently run any analytics or visitor-tracking software. If that changes, this policy will be updated to say so plainly, including what's collected and why.

Children's privacy

This site does not knowingly collect information from anyone, of any age, because it does not collect information at all in its current form.

Changes to this policy

If this site starts collecting information it doesn't collect today, this page will be updated to describe exactly what and why before that change takes effect.
