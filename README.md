# Drift: practice for game-based assessments

**Live site:** https://dh4ny4.github.io/drift-practice/

Many graduate and internship applications now include game-based psychometric assessments. Candidates play short mini-games that measure things like memory, attention and attitude to risk. You usually can't practise them before the real thing, so the format can catch you off guard.

Drift lets you try that format first. The aim is for the mechanics to feel familiar, not to "learn the answers". There are no right answers to learn.

## Features

- **11 mini-games**, each based on a mechanic candidates commonly report seeing:

  | Game | What it practises |
  |---|---|
  | Sequence | Repeating a growing tile pattern while ignoring decoy flashes (memory, controlled attention) |
  | Direction | Reacting to the middle arrow among distractors, and holding back on a stop signal (focus, response inhibition) |
  | Team | Setting a price each round against an opponent that reacts to you (cooperation, strategy) |
  | Ticket | Switching rules depending on where a card appears (cognitive flexibility) |
  | Preparation | Pumping a balloon for value or banking it before it pops (risk and reward) |
  | Expression | Matching faces to emotions against the clock |
  | Security | Stopping a moving dial in a target zone |
  | Energy | Learning a hidden pattern to keep a generator powered |
  | Patterns, Analysis, Weather | More pattern-learning and judgement tasks |

- **Full mock test mode:** 7 games picked at random and played back to back like the real thing, with a scorecard at the end.
- **Guide page** explaining what psychometric assessments are and how game-based versions differ from traditional tests.
- **Light and dark themes**, plus a privacy page.

## Built with

- Plain HTML, CSS and JavaScript, with no frameworks and no build step.
- Hosted on GitHub Pages.

## Run it locally

```bash
git clone https://github.com/DH4NY4/drift-practice.git
cd drift-practice
# open index.html in your browser
```

Drift is an independent practice tool. It is not affiliated with or endorsed by any assessment provider, and it doesn't reproduce any real assessment.
